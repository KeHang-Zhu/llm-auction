% ---------- Setup / framing bullets ----------
% \item Knobs with data: temperature (0.1/0.5/1.0, GPT-4o, 8 mechanisms);
%   risk personas (averse/neutral/seeking; SP for 4 models, FP+TP N=3 for GPT-4o);
%   prospect frames (loss/gain/mixed/endowment/WTA-WTP; same coverage as personas);
%   rule-explanation on/off (GPT-4o, sealed-bid formats only).
% \item Distance to humans measured on three axes: level (\Delta SMAD), direction
%   (overbid-share gap), shape (Wasserstein-1 vs reconstructed human bid
%   distributions). Human targets: plots/auction_human.csv.
% \item Canonical baselines: intervention cells are tested against the same
%   model's pooled axis1/2/3 baselines (personas) or loss-aversion baseline
%   (frames); temperature and explanation cells against the V10 anchors.

% ---------- (a) LEVEL: best setting per mechanism (GPT-4o) ----------
% \item FP: T=1.0 closes the level gap almost exactly: SMAD 25.50 [23.49,27.69]
%   vs human 24.76 (\Delta=+0.74); untuned anchor 28.11.
% \item SP: WTA--WTP frame is best: 7.24 [6.02,8.56] vs human 5.65 (\Delta=+1.59);
%   improvement over its own baseline $-3.57$ SMAD (Welch $p=0.005$).
% \item SP-APV: untuned anchor already best (10.95 vs 9.31); both temperatures hurt.
% \item AC / AC-B: LLMs are \emph{too rational}: SMAD 0.83 / 0.48 vs human 3.54 / 5.83.
%   Raising temperature to 1.0 adds human-like noise and moves TOWARD humans
%   (1.02 / 2.19) -- the only case where a knob works by degrading the LLM.
%   (Caveat: AC-B T=1.0 has n=8 exits.)
% \item CV-FP: temperature helps (T=0.1: 39.0; T=1.0: 42.9 vs human 47.6; anchor 59.99,
%   level test $p\le0.016$). CV-SP: all settings remain 15--22 SMAD above human 18.23.
% \item TP: cardinal failure under EVERY setting. Best cell in the entire grid:
%   T=0.1, N=5: SMAD 44.11 vs human 7.66 (n=5 Kagel--Levin). At N=3 all persona/frame
%   cells sit at SMAD 106--131 (equilibrium 2v; LLMs bid $\approx$ value).

% ---------- (b) DIRECTION: only risk-seeking moves it ----------
% \item Human overbid-vs-value shares: FP 0.4\%, SP 67.2\%, TP 89.8\%.
% \item GPT-4o baselines: FP 0\%, SP 0.4\% (axis baseline; V10 anchor 16.7\%), TP3 0.2\%.
% \item Risk-seeking persona (GPT-4o): SP overbid $0.4\%\to45.3\%$ ($p<10^{-4}$),
%   TP3 $0.2\%\to56.5\%$ ($p<10^{-4}$) -- direction gaps fall from 66.8 to 21.9pp (SP)
%   and 89.6 to 33.3pp (TP3). It also improves TP3 level ($-14.4$ SMAD, $p=0.011$)
%   and SP shape (W1 23.8$\to$14.8pp).
% \item COST: in FP the same persona induces dominated bids: overbid-above-value
%   $0\%\to18.0\%$ vs human 0.4\% ($p<10^{-4}$); FP SMAD $+4.6$ ($p=0.002$).
% \item No other knob moves direction: under temperature, frames, and explanation
%   the SP overbid share never exceeds 17\% (gap $\ge50$pp); risk-averse pushes all
%   overbid shares to 0.
% \item Direction rank table (rank\_core\_dir\_gap.csv): risk-seeking is rank 1 of 15
%   on SP and TP3 and rank 15 of 15 on FP.

% ---------- (c) VERDICT: no portable setting ----------
% \item No setting is in the top half of both the level and the direction ranking
%   on all three core mechanisms (FP, SP, TP3) -- see rank\_core\_*.csv.
% \item Level winner (worst-case rank): WTA--WTP frame (6/15); direction winner on
%   SP+TP: risk-seeking; the two are disjoint and risk-seeking breaks FP.
% \item Interpretation bullet: matching human overbidding in SP/TP requires a
%   disposition that violates the sharpest human regularity in FP (almost never
%   bidding above value). Cardinal calibration is mechanism-specific by
%   construction, not by accident of the grid.
% \item Model-specificity (SP, risk-seeking, SMAD vs human 5.65 / overbid vs 67.2\%):
%   gemma-3-27b $20.71\to5.87$ / $26\%\to56\%$ (best cardinal match in grid);
%   gemini-2.0-flash $11.74\to4.92$ / $0\%\to82\%$;
%   gpt-4o $11.38\to10.48$ / $0.4\%\to45\%$;
%   claude-3.5-haiku $9.53\to35.03$ / $43\%\to93\%$ (overshoots badly).
%   A persona calibrated on one model does not transfer to another.
% \item Temperature is not a cardinal dial: SP SMAD is non-monotone in T
%   (15.07 / 8.86 / 13.15 at T=0.1/0.5/1.0; both deviations from 0.5 significant,
%   $p\le10^{-4}$); its only clean use is noising the too-perfect clock formats.
% \item Rule-explanation on/off: no-op. Level differences $\le0.16$ SMAD on FP, SP,
%   SP-APV (all $p\ge0.53$); TP3 $+3.0$ ($p=0.53$); only a small TP3 direction shift
%   (19.4\%$\to$12.6\%, $p=0.02$). [Caveat: manipulation not verifiable from saved
%   prompts; contrast rests on the recovered git tree ce36a78b. Phrase as ``no
%   detectable effect''.]
